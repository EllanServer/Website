# 计划 · 新建《艾尔岚玩法百科》电影化长页

## 一、背景与前提（已核实）

- `index.html` 里 **两处**已经指向 `gameplay.html`（导航「玩法百科」第 38 行、`playbook-cta` 按钮第 136 行），但 `Glob *.html` 确认**根目录只有 `index.html`** —— 这两个入口目前是死链。本轮就是把这个文件补上。
- `playbook-cta` 现有文案「从四季农耕、跨维度钓鱼，到食谱解谜、酿造研究与每日屠龙，完整机制都在这里」与新文档内容完全吻合，**首页无需任何改动**（符合你选的「只加入口，不改现有内容」）。
- 现有设计体系（`design-qa.md` + `css/main.css`）必须完整沿用：
  - 黑底 `#0b0d09` / 米白 `#f4f2e6`，金 `#f5be4f` → 草绿 `#8fdd55` → 钻石青 `#5ed6c4` 渐变，红石红 `#e05a4d` 仅作离线/危险语义
  - Fusion Pixel 像素字体只用于 logo / 巨标 / kicker；正文与引文用霞鹜文楷 GB
  - `.reveal` IntersectionObserver 渐入、`clamp()` 流式字号、`?shot=1` QA 钩子
- 素材结论：`img1~img6`(2000×1600, 3.4–5.3MB)、`banner2.png`(4.19MB) 体积过大；`start.jpg`、`zhandian.jpg` 经目验**不是 MC 实机截图**（太空渲染 / 星空插画），与页脚「画面均为本服务器实机截图」声明冲突，全部不使用。
- 环境：`convert` 在 MSYS 下不可用（"Invalid drive specification"），无 magick/cwebp/sharp；Python Pillow 12.2.0 可用，Edge 可用于无头截图 QA。本轮**不需要任何图片处理**。

## 二、总体方案

新建三个文件，首页零改动：

| 文件 | 作用 | 规模 |
|---|---|---|
| `gameplay.html` | 玩法百科长页 | 约 1000 行 |
| `css/gameplay.css` | 本页专属样式（不污染 `main.css`） | 约 850 行 |
| `js/gameplay.js` | 滚动进度条 + 章节 sticky 导航 scrollspy + 数字滚动 | 约 130 行 |

**复用而非重写**：`css/main.css` 提供导航、按钮、`.kicker`、`.reveal`、`.section-heading`、footer、modal、toast 全套基座；`js/main.js` 提供页头滚动态、reveal、hero 视差、复制 IP、toast、`?shot=1` 钩子。已逐项核对 `main.js` 的守卫，可安全复用：

- `showDownloadOptions` / `closePopup` 有 `if (!modal) return`
- `qr-toggle`、`bookmark-btn` 有存在性判断
- scrollspy 只收集 `href` 以 `#` 开头的 `.nav-link`；新页主导航全部是 `index.html#xxx` 跨页链接 → 数组为空，不产生副作用
- hero 视差依赖 `#hero-art-img` + `.hero`，新页复用同名钩子即可继承

**不引入 `server-status.js`**：它开头是 `if (!icon || !motd) return`，新页没有状态卡就会直接退出，导致 `nav-live` 永久停在「连接中」。因此新页导航右侧改为「复制 IP」+「在线游玩」两个按钮，不放实时状态点。

## 四、电影化表现手段（本轮的核心）

「电影化」在这一页不是多加几张大图，而是**用镜头语言组织滚动**。八种手段，全部纯 CSS/原生 JS：

**1. 开场黑幕与片名（HERO）**
不用照片。深黑底 + 双层径向光晕（金色顶光 + 青色底光）+ 极淡 CSS 像素网格；巨标 `GAMEPLAY` 用像素字 `clamp(64px, 13vw, 190px)` 配 `grad-anim` 渐变流动，下方中文副题「艾尔岚 · 玩法全书」逐级 `heroRise` 延迟入场（复用 `main.css` 现成关键帧）。三个数据巨号（`204` 自定义附魔 / `29` 款酒水 / `370+` 家具）用 `js/gameplay.js` 做一次性数字滚动，进入视口才触发。

**2. 顶部滚动进度条**
固定在页头下沿的 1.5px 渐变线，宽度随阅读进度推进 —— 长页的「胶片进度」。`requestAnimationFrame` 节流，`transform: scaleX()` 走 GPU。

**3. 章节 sticky 导航（幕次标尺）**
页头下方一条 `position: sticky` 的横向章节条（序章/教学/世界/玩法/经济/任务/交易/闭环），当前章节高亮 + 渐变下划线。移动端横向滚动、隐藏滚动条。这是长页不迷路的关键。

**4. 幕间黑场（章节转场）**
每章之间插入 `.reel-break`：一条从中心向两侧淡出的渐变细线 + 中央像素幕号 `CHAPTER 03`。给滚动一个呼吸停顿，像电影切幕。

**5. 视差纵深**
每章标题背后浮一个巨大的半透明像素数字（`00`–`07`，`opacity: .05`），随滚动以不同速率轻微位移，制造前后景分离。`prefers-reduced-motion` 下静止。

**6. 台词式对白卡（NPC 教学章）**
把 NPC 原话做成真正的引文：左侧竖排渐变引号条 + 霞鹜文楷斜体台词 + 下方角色名牌（`老农大爷 · 农耕导师`）。原文档里那句「在不同的季节适合种植不同的作物，农作物无法在它们不适应的季节存活，这个需要你自己探索」原样保留 —— 这句本身就是最好的宣传语。

**7. 焦点镜头（关键系统段）**
农耕/钓鱼/烹饪/酿酒四段各占一屏，采用**左文右视觉**的宽银幕布局（移动端堆叠）。右侧「视觉」不是照片，而是纯 CSS 构件：
- 农耕 → 四季轮盘（春夏秋冬四扇区，各标注可种作物数）
- 钓鱼 → 星露谷式收杆条（渐变色块 + 指针，CSS 动画来回扫动）
- 烹饪 → 谜语卡（正面显示食材谜语，`:hover`/`:focus-within` 翻转揭示答案）
- 酿酒 → 五星进度条（0→5 星逐级点亮 + 陈酿等级刻度）

这四个构件是这一页最有分量的原创部分，也是「排版驱动」方案能顶住无图压力的底气。

**8. 少量实机照片作为章节 key-art**
只用首页已在用的 6 张（`gameplay-economy.jpg` / `gameplay-daily.jpg` / `gameplay-life.jpg` / `world-street.jpg` / `world-night.jpg` / `cover.jpeg`），全部 `loading="lazy"`，覆盖 `linear-gradient` 压暗 + 文字压图，作宽幅转场带使用。**零新增图片，零体积增长。**

## 五、逐章实现细节

### CH.00 序章
沿用首页 `.statement` 巨标手法：`原版只是一个起点` 大字 + 四句排比（种地是一门学问 / 钓鱼是一场游戏 / 做菜是一场解谜 / 酿酒是一场实验）做成四格网格，每格一个渐变序号。下方单独一块**高版本首家徽章**：`MC 26.2 · 高版本首家`，突出森罗厨房 + 森罗酒馆插件化这个最硬的差异点。

### CH.01 沉浸式教学
6 张 NPC 对白卡（老农大爷 / 渔夫 / 厨师 / 酒馆师傅 / 荷官庄家 / 悬赏经纪人），每张含台词 + 教学要点列表。木匠、宠物店、玩具店、魔法商店、银行、裁缝等收进一行「主城 60 余位 NPC 各司其职」的标签墙。悬赏经纪人卡片保留「可选玩法，不想参与也不会被强迫」这句 —— 这是重要的玩家预期管理。

### CH.02 四大区域
四张区域卡，每张标注定位 + 特色 + 产出声望。**明确写出「不再区分生存服/生电服，哪里都可以造红石机器」**，赤铁原标注 `Leaves 核心`。首页 hero chip 已有「不限红石」，此处呼应。

### CH.03 玩法系统（本页主体）

| 段 | 主线内容 | `<details>` 收纳 |
|---|---|---|
| 01 四季农耕 | 四季轮盘 + 完整农事工序 8 步 + 摇钱树/洒水器/维度花盆 | 30 余种作物完整清单 |
| 02 跨维度钓鱼 | 收杆条构件 + 装备体系 + 三维度 + 5 种比赛类型 | 鱼竿/鱼饵/配件清单 |
| 03 森罗厨房 | 谜语翻转卡 + 7 类厨具 + 「猜谜→试做→解锁」循环图 | 200+ 菜品清单 |
| 04 森罗酒馆 | 五星研究条 + 6 步工序 + 星级解锁阶梯 + 提交手法 | 29 款酒水清单 |
| 05 附魔 204 种 | 八级稀有度色阶（用原文的中国传统色名：汉白玉/毛绿/霁青/夹竹桃红/淡橘橙/油菜花黄/鹤顶红/粉团花红）+ 五大功能族 + 技能触发 | 功能附魔分族清单 |
| 06 家具装饰 | 主题墙 + 370+ 件 + 声望解锁（强调「声望只解锁资格，不扣除」） | 主题与品类清单 |
| 07 屠龙猎手 | 四龙时刻表（10:30/15:30/19:30/21:30）+ 伤害排名 100/70/40% + 击杀者 +10% | 各龙掉落池 |
| 轻量三联 | 刺杀悬赏 / 娱乐城 7 种游戏 / 饰品外观 | — |

稀有度色阶是个亮点：八种中国传统色排成一条渐变带，配「附魔书外观随最高品质附魔自动变化」的说明。

### CH.04 经济系统
四种货币做成矩阵卡（金币 / 栖风谷声望 / 赤铁原声望 / 艾尔星辉）。动态定价用一条**带上下限保护区间的价格波动示意图**（纯 CSS：折线用 `clip-path` 或分段渐变，上下限用虚线带），标注原文的金胡萝卜 `7.2~9.2` 实例，并列出四个影响因子（玩家行为 / 时间 / 服务器经济 / 法定节假日）。「甚至中国的法定节假日」这个细节要留，它最能体现系统深度。

### CH.05 任务与订单
每日委托给具体样例（番茄×16 + 红烧鱼×2 + 活塞×4 → 500 金币 + 双区声望 4）。每周委托 10 类做成紧凑列表。限时订单强调时限压力（熟竹筒饭×10 限时 16 分钟）与那句结论：**「你的手艺，就是主城的刚需」**。保留原文「以上为当前配置示例，任务会持续更新」的免责括注。

### CH.06 玩家交易
四条渠道横排（每晚拍卖会 / 每周法拍 / 玩家地摊 / 商铺租赁）。

### CH.07 玩法闭环
把原文的 ASCII 流程图重画成 CSS grid 流程图：农耕+钓鱼 → 原料互通 → 烹饪/酿酒 → 订单委托 → 金币+声望 → 再投入。连接线用伪元素渐变线。下方新手成长路线做成 6 站竖向时间轴（入服 → NPC 入门 → 第一桶金 → 学手艺 → 接单冲榜 → 生活大师）。

## 六、技术与质量要求

**HTML**
- `lang="zh-CN"`，独立 SEO：title「玩法百科 · Ellan 艾尔岚」、description、og:*、`<link rel="canonical">`
- 导航结构与首页一致但「玩法百科」为 `active`，其余链接改为 `index.html#intro` 等跨页形式
- 加 `.skip-link`、`<main id="main">`、章节用 `<section aria-labelledby>`、`<details>` 原生可达
- 严格避免与首页重复的 ID 冲突（本页独立文件，但 `hero-art-img`、`toast-root` 等复用名需与 `main.js` 期望一致）

**CSS**
- 新建 `css/gameplay.css`，在 `main.css` 之后加载，**只做增量，不改一行 `main.css`**（首页零风险）
- 所有颜色走现有 `var(--gold/--leaf/--aqua/--line/...)` 令牌，不引入新色值
- 断点沿用 `1120px / 860px / 600px` 三档
- `prefers-reduced-motion` 下关掉进度条动画、视差、扫动条

**JS**
- 新建 `js/gameplay.js`（IIFE + `'use strict'`，与现有风格一致，无依赖）
- 三个功能：滚动进度条、章节 scrollspy、数字滚动
- 全部加存在性守卫；数字滚动在 `html.qa-shot` 下直接落终值（照抄 `server-status.js` 的 tween 处理）
- 引入 `main.js` 但**不引入 `server-status.js`**（原因见第二节）

**验证**
1. `node --check js/gameplay.js`
2. 检查 `gameplay.html` 无重复 ID、所有本地资源路径存在
3. Edge 无头截图（带 `?shot=1`）逐章目验：hero / 章节导航 / 四个 CSS 构件 / 稀有度色阶 / 价格图 / 闭环图 / 时间轴
